## Traps learned

- **Windows `npm run cli` and multi-line text:** it cuts the text at the first newline and drops later flags, while still reporting `ok`. Call `node node_modules/tsx/dist/cli.mjs src/cli.ts ...` directly.
- **Never `npx`** for tools not listed in `package.json`.
- **Upload root:** set `TEAMS_MCP_UPLOAD_DIR` for files under `.worktrees` or `.tmp`.
- **Teams session expires overnight:** a plain `login` renews it silently.
